## Desafio 03:

**Prompt usado:**  
```
Atue como um cientista de dados especialista no banco de dados Neo4j.
Sua tarefa é fazer a modelagem de uma aplicação de rede sociais para apreciadores de Livros que permita obter insights com base no engajamento e as conexões dos usuários da plataforma.

Esta aplicação deverá possibilitar a resposta de perguntas complexas sobre as interações de usuários, popularidade de conteúdo e comunidades de interesse.
Como exemplos destas perguntas temos: qual o público alvo, como estas pessoas estão relacionadas, qual a menor distância de uma pessoa para outra, recomendações de livro e usuários para seguir, qual a postagem mais curtida em um mês.
Você pode incluir mais perguntas que achar relevantes.

Inicie com criando uma imagem .png contendo o grafo, os nós e seus relacionamento.

Em seguida, gere em três arquivos distintos o código para criar o grafos, os nós e relacionamentos. Os códigos para inserir dados, pelo menos 20 usuários, 50 livros, 30 posts. E o código para executar as consultas.

```
